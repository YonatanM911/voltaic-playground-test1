# Source Navigation

This project is a TanStack Start + React + TypeScript app for an interactive circuit lab called Voltica Laboratories. The app is mostly client-side UI and simulation logic, with TanStack Start server wrappers for SSR/error handling.

Note: many user-facing strings in the checked files appear as mojibake in this workspace, but they are intended to be Hebrew RTL labels and copy.

## Project Shape

- Framework: TanStack Start, TanStack Router, React 19, Vite.
- Styling: Tailwind CSS v4 via `src/styles.css`, with shadcn-style UI wrappers in `src/components/ui`.
- Main domain: circuit lab canvas, palette, component editing, unit settings, SVG symbols, and an MNA-based circuit solver.
- Routes: `/`, `/lab`, `/guide`, `/settings`.
- State persistence:
  - Theme: `localStorage`, key `voltica-theme`.
  - App settings: `localStorage`, key `voltica-settings-v2`.
  - Lab state and saved structures: `sessionStorage`, keys `voltica-lab-state` and `voltica-session-structures`.

## High-Value Entry Points

- `src/routes/lab.tsx`: owns the circuit lab state and wires together canvas, toolbar, palette, import dialog, edit dialog, solving, undo/redo, search, clipboard, persistence, and navigation confirmations.
- `src/components/lab/LabCanvas.tsx`: pointer interaction layer for pan, zoom, drag, selection, marquee selection, component rendering, meter readings, and warning labels.
- `src/lib/lab/solver.ts`: electrical simulation engine. Uses modified nodal analysis and additional logic for open circuit warnings and meter readings.
- `src/lib/lab/types.ts`: core domain model for component types, placed components, terminals, snapping, bounds, labels, and default names.
- `src/lib/lab/symbols.tsx`: SVG drawing definitions for all circuit components.
- `src/lib/lab/units.ts`: SI unit prefix conversion and formatting.

## `src` Root Files

### `src/router.tsx`

Creates the TanStack Router instance with a `QueryClient`, the generated `routeTree`, router context, scroll restoration, and default preload stale time.

Use this when changing router-level context or query client initialization.

### `src/routeTree.gen.ts`

Generated TanStack Router route tree. It imports the route modules and declares route typings for `/`, `/guide`, `/lab`, and `/settings`.

Do not edit this file manually; it is regenerated by TanStack Router tooling.

### `src/server.ts`

Cloudflare/TanStack server entry wrapper. It lazily imports `@tanstack/react-start/server-entry`, delegates fetch handling, and converts catastrophic swallowed SSR JSON errors into a branded HTML error page.

Also imports `lib/error-capture` so the original thrown error can be recovered when h3 turns it into a generic 500 response.

### `src/start.ts`

Creates the TanStack Start instance and installs server middleware that catches non-HTTP errors and returns `renderErrorPage()` with status 500.

Use this when changing request middleware behavior.

### `src/styles.css`

Global Tailwind v4 setup and design tokens. It imports Tailwind and `tw-animate-css`, maps CSS variables into Tailwind theme colors, and defines light/dark OKLCH palettes, grid color, chart colors, sidebar tokens, base body styles, and border color defaults.

Use this for app-wide colors, radii, CSS variables, and base styling.

## Routes

### `src/routes/__root.tsx`

Root TanStack route. Defines global head metadata, links `styles.css`, supplies `RootShell`, wraps pages in `QueryClientProvider`, and defines built-in 404 and route error UI.

Important pieces:
- `RootShell`: emits HTML/head/body and injects an early script to apply the persisted dark/light theme before hydration.
- `RootComponent`: provides the query client and renders `<Outlet />`.
- `NotFoundComponent` and `ErrorComponent`: route-level fallback screens.

### `src/routes/index.tsx`

Home page for Voltica Laboratories. Applies current theme, lets the user toggle light/dark mode, and links to `/lab` and `/settings`.

This is the first screen and contains the app branding and footer credit.

### `src/routes/lab.tsx`

Main lab page and the central orchestrator for the app. It owns:
- `components`: all placed circuit parts.
- `tool`: select or pan.
- `selectedIds`, search text, clipboard, saved structures, import dialog, edit dialog, and confirm dialogs.
- `view`: canvas pan and zoom.
- undo/redo stacks.
- session persistence for lab state and saved structures.
- keyboard shortcuts for rotate, delete, copy, paste, cut, duplicate, focus, undo, redo, and escape.

It calls `solve(components)` and passes the result down to `LabCanvas` and `EditDialog`.

Navigation note: going home confirms and removes the persisted lab state. Clearing the board also removes persisted lab state.

### `src/routes/guide.tsx`

Guide/learning route. Shows an ordered list of lesson cards that open YouTube searches in a new tab. Uses static lesson metadata and links back to `/lab`.

### `src/routes/settings.tsx`

Settings route. Lets the user:
- toggle dark mode.
- set default units for voltage, current, and resistance.
- toggle whether component names are displayed on the lab canvas.

Uses `useAppSettings()` and `lib/lab/units`.

## Lab Components

### `src/components/lab/LabCanvas.tsx`

Interactive SVG canvas. Responsibilities:
- Tracks canvas size.
- Converts screen coordinates to world coordinates.
- Handles pointer gestures for panning, dragging components, marquee selection, and two-finger pinch zoom.
- Handles wheel zoom around the pointer.
- Renders grid lines for the visible world.
- Picks components by transformed local bounds.
- Renders selected/search-highlight rectangles, circuit symbols, labels, meter readings, open-circuit warnings, and a floating action bar.

Key props:
- `components`, `setComponents`: circuit state.
- `tool`: `"select"` or `"pan"`.
- `solve`: result from `lib/lab/solver`.
- `view`, `setView`: pan/zoom camera state.
- `selectedIds`, `setSelectedIds`: selection state.
- callbacks for quick edit, copy, delete, rotate, save selection, and drag snapshots.

### `src/components/lab/LabToolbar.tsx`

Fixed top toolbar for navigation and canvas actions. Provides buttons for home, settings, undo, redo, select, pan, guide, rotate, zoom in/out, focus camera, clear board, and search.

It is presentational; behavior is passed in by `routes/lab.tsx`.

### `src/components/lab/Palette.tsx`

Bottom draggable component palette. Contains standard circuit parts:
`wire`, `wire_corner`, `wire_t`, `wire_plus`, `battery`, `resistor`, `bulb`, `switch`, `diode`, `ammeter`, `voltmeter`, `ohmmeter`, and `multimeter`.

Important behavior:
- Uses a pointer movement threshold so mobile horizontal swipes scroll the palette instead of starting accidental drags.
- Pressing `R` while dragging rotates the ghost.
- Calls `onDrop` with component type, rotation, and final client coordinates.
- Has an add/import button that opens `ImportDialog`.

### `src/components/lab/EditDialog.tsx`

Dialog for editing one placed component. Lets the user rename a component, edit supported quantities, choose per-component unit overrides, view solved readings, toggle switch open/closed, save, cancel, or delete.

Important details:
- Editable quantities are controlled by `CAPABILITIES`.
- Stored numeric values are SI base units.
- Display values are converted through `units.ts`.
- It calls `onUpdate` immediately for switch state changes and `onSave` for validated field commits.

### `src/components/lab/ImportDialog.tsx`

Dialog opened from the palette add button. It has two tabs:
- special parts: logic gates (`AND`, `OR`, `NOT`, `BUFFER`, `XOR`, `NAND`, `NOR`, `XNOR`).
- saved structures: session-saved groups of components.

Exports `SavedStructure`, which is used by `routes/lab.tsx`.

## Lab Library

### `src/lib/lab/types.ts`

Core circuit domain types and geometry helpers.

Contains:
- `ComponentType`: union of wires, sources, consumers, meters, switches, diodes, and logic gates.
- `PlacedComponent`: persisted shape of a component on the canvas.
- `CAPABILITIES`: which quantities can be edited per component type.
- `COMPONENT_LABEL_HE`: user-facing labels.
- `NAME_PREFIX`: auto-name prefixes.
- `GRID` and `COMPONENT_LENGTH`.
- `snap()`: grid snapping.
- `terminalPositions()`: two-terminal geometry.
- `allTerminalPositions()`: multi-terminal connector/gate geometry.
- `isConnector()` and `isMultiTerminal()`.
- `componentBounds()`: local-space bounds for selection/hit UI.
- `parseField()`: numeric field validation.
- `nextComponentName()`: unique auto-naming.

### `src/lib/lab/solver.ts`

Circuit solver and warning generator.

Main flow inside `solve(components)`:
1. Create nodes from component terminal positions.
2. Merge wire/connector nodes with union-find.
3. Build conducting adjacency for loop detection.
4. Identify active connected components with closed battery loops and consumers.
5. Run modified nodal analysis for active components.
6. Fill per-component voltage/current/resistance readings.
7. Generate open-circuit, missing-source, missing-consumer, and switch-open-style warnings.
8. Compute ohmmeter/multimeter equivalent resistance.

Important internal concepts:
- Batteries and diodes are voltage sources in MNA.
- Ammeters are tiny resistance branches.
- Voltmeters and multimeters are high-impedance loads.
- Connectors and gates are treated like wires electrically.

There is a helper `computeAmmeterCurrent()` left in the file, but the current main solve path derives ammeter readings through the tiny-resistance branch model.

### `src/lib/lab/symbols.tsx`

SVG symbol renderer for circuit components.

Exports:
- `ComponentSymbol`: low-level symbol by `ComponentType`.
- `PaletteSymbol`: scaled symbol for palette tiles.
- `PlacedSymbol`: world-positioned and rotated symbol for the canvas.

Includes drawing logic for wires, junctions, battery, resistor, bulb, switch, diode, meters, and logic gates.

### `src/lib/lab/units.ts`

SI unit conversion and display formatting.

Contains:
- `Quantity`: `"voltage" | "current" | "resistance"`.
- base units: V, A, ohm.
- SI prefixes from nano through tera.
- `prefixedUnits()`, `unitFactor()`, `fromBase()`, `toBase()`, `autoUnit()`, and `formatValue()`.

All stored numeric values in the lab are SI base values; this file handles display/edit conversion.

### `src/lib/lab/settingsStore.ts`

Small settings store built on `localStorage` plus a custom `voltica-settings` window event.

Exports:
- `AppSettings`: default units and `showNames`.
- `loadSettings()`.
- `saveSettings()`.
- `useAppSettings()`: React hook returning `[settings, updateSettings]`.

## Shared Library

### `src/lib/theme.ts`

Theme persistence and DOM application. Uses `localStorage` key `voltica-theme`, defaults to dark mode, and toggles the root `.dark` class plus `color-scheme`.

Exports `Theme`, `getInitialTheme()`, `applyTheme()`, and `setTheme()`.

### `src/lib/utils.ts`

Exports `cn()`, a common shadcn helper that combines `clsx` with `tailwind-merge`.

### `src/lib/error-capture.ts`

Global error/rejection capture for SSR. Stores the last captured error for five seconds so `server.ts` can log the original error when the server layer only returns a generic JSON 500 body.

### `src/lib/error-page.ts`

Exports `renderErrorPage()`, a standalone HTML string for branded server-side error responses.

## Hooks

### `src/hooks/use-mobile.tsx`

React hook that returns whether the viewport is below 768px. Uses `matchMedia` and updates on media query changes.

## Common Navigation Paths

- To change what components exist: start in `src/lib/lab/types.ts`, then update `src/lib/lab/symbols.tsx`, `src/components/lab/Palette.tsx`, possibly `src/components/lab/ImportDialog.tsx`, and finally `src/lib/lab/solver.ts` if the component needs electrical behavior.
- To change canvas interactions: start in `src/components/lab/LabCanvas.tsx`; state ownership usually lives in `src/routes/lab.tsx`.
- To change toolbar controls or shortcuts: toolbar buttons live in `src/components/lab/LabToolbar.tsx`; keyboard shortcuts live in `src/routes/lab.tsx`.
- To change calculations or readings: start in `src/lib/lab/solver.ts`; formatting for readings is split between `src/components/lab/LabCanvas.tsx`, `src/components/lab/EditDialog.tsx`, and `src/lib/lab/units.ts`.
- To change theme colors: edit `src/styles.css`; behavior for toggling/persisting theme is in `src/lib/theme.ts`.
- To change settings persistence: edit `src/lib/lab/settingsStore.ts`; UI is in `src/routes/settings.tsx`.
- To change routing or page metadata: route files are in `src/routes`; generated route output is `src/routeTree.gen.ts`.
